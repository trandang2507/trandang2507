## 🚀 Featured Projects

### 🏥 [ClinicAppointmentSystem](https://github.com/trandang2507/ClinicAppointmentSystem) · *in progress*

RESTful backend for booking medical appointments.

- **Auth:** Spring Security, JWT + refresh token, BCrypt, role-based access control
- **Core:** doctor and specialty lookup, booking, appointment status updates, visit notes, admin statistics
- **Business logic:** doctor schedule validation and double-booking prevention
- **Event-driven:** Apache Kafka producer/consumer for appointment notifications (created, cancelled, status changed)
- **Quality & DevOps:** validation, centralized error handling, Swagger/OpenAPI docs, Docker Compose (PostgreSQL + Kafka)

`Java 17` `Spring Boot` `Spring Data JPA` `PostgreSQL` `Kafka` `Docker`
